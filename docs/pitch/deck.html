The problem

A human in a cab never sets a ceiling.

They watch the meter and pay what it says. An AI agent cannot — to spend on your behalf it must commit to an amount before that amount exists: before the meter runs, before the substitutions, before the kWh.

Ceiling too low
sale lost
The debit is declined. NPCI grants zero retries for this class of decline.
Ceiling too high
money stranded
The customer's funds sit blocked for nothing — up to 90 days on the rail's own terms.

Every agent payment is a forecast.
Nobody built the settlement for that.

Architecture

The LLM proposes. The policy engine disposes. The rail enforces.

UNTRUSTED · the model Gemini or Claude, interchangeable — holds zero authority; every tool call is only a proposal. BYO-key safe.
↓ proposes
GOVERNED · policy engine Deterministic, no model call. Checks the human's envelope, then the rail's cited capabilities and limits. Refusals carry the circular that decided them.
↓ approved actions only
ENFORCED · the rail UPI SBMD · Razorpay · Setu — the outermost boundary is a bank, not a prompt.
EVIDENCE CHAIN Every proposal, verdict, transition — and every refusal — signed and hash-linked. Verifies with zero trust in us.

No code path reaches money without a verdict — pinned by test, then proven over thousands of random action sequences (property-based): debited + released ≤ blocked · blocked ≤ budget. No counterexample.

The discipline that makes it trustworthy

Every capability is cited — or it is refused.

tierusable as fact
PRIMARYyesNPCI circular, RBI directive — quoted verbatim
OBSERVEDyesmeasured against the live API — the quote is the rail's response
SECONDARYyesPSP docs, for that PSP's own behaviour
MARKETINGneverblogs, comparison tables
UNVERIFIEDneverabsence of evidence is not permission
For one day, this system refused its own core mechanism — partial debit rested on vendor docs until we read NPCI OC-228 off the scanned PDF. The gate held against us too. That refusal is still in the test suite, as a record.

The ceiling model, honestly. Conformal quantile regression on 300k real NYC metered fares (no public Indian dataset exists — the method transfers, the coefficients don't). Finding: the coverage guarantee is distribution-free but not shift-free — 18 of 20 configs missed nominal under a real temporal split. Recency calibration narrows the gap ~10× (−3.55pp → +0.91pp). Stated before you ask

What this is not.

  • The SBMD demo runs on a simulator — every semantic cites the circular it models; the real-rail run is gated on PSP enablement, and the real Razorpay path is the different-but-honest capture-then-refund.
  • Consent binding is a stated placeholder — adjudication proves the settlement conformed to the recorded grant, not that a human's key signed it; AP2's cnf slot is where that lands.
  • No risk model of ours — Razorpay ships RTO Shield; risk enters through a seam, not a rewrite.
  • No win-rate, no "first," no invented data — negative findings are promoted, not buried. The two-round adversarial review that killed our own v1 thesis ships in the repo.
